# Ani Vibes

Create a modern anime discovery web app.

The app should be responsive and work well on both desktop and mobile.

For this first version, focus ONLY on creating the frontend UI. Do not add authentication, database, external APIs, or payment systems yet.

Create these pages:

Home page

Modern anime streaming/discovery style

Hero section with a featured anime

Popular anime section

Latest anime section

Recommended anime section

Anime cards with poster, title, score, year, and genres

Search page

Search input

Filter by genre

Filter by year

Japanese title

Episode list UI

Display favorite anime cards

Empty state when there are no favorites

Login page

Register page

Email

Password

Register button

Use mock anime data for now.

Design requirements:

Dark anime-inspired theme

Clean modern UI

Rounded cards

Smooth hover effects

Responsive layout

Mobile-friendly navigation

Bottom navigation on mobile

Sidebar or top navigation on desktop

Use high-quality placeholder anime artwork

Make the interface feel like a real production anime application

Do not implement real authentication or database yet.
Do not use copyrighted anime images as permanent assets.
Keep the code clean, modular, and easy to extend later.
